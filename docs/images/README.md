# Visual assets

These repository-owned assets explain the MP Frontend ecosystem without depending on a private design
file or external image host.

- `ecosystem-light.svg` and `ecosystem-dark.svg` are the theme-aware README architecture artwork.
- `social-preview.svg` is the editable source for repository and announcement artwork.
- `social-preview.png` is the 1280 × 640 upload-ready GitHub social preview.

Keep the diagram aligned with the trust boundaries in [`../ARCHITECTURE.md`](../ARCHITECTURE.md). Do not
add consumer branding, private design identifiers, or product-specific screenshots to this directory.
